Equipment Downtime Tracker

Project Overview
The Equipment Downtime Tracker is a cloud-based application designed to help manufacturing companies report, record, and monitor equipment failures.

Problem Statement
Manufacturing companies can experience production delays when equipment failures are not reported or documented properly. This project aims to provide a centralized system for recording equipment failures and tracking their status.

Project Goals
* Allow employees to submit equipment failure reports.
* Store equipment failure information in a cloud database.
* Allow users to retrieve previously submitted reports.
* Monitor application performance and errors.
* Establish security boundaries and access controls.
* Test application behavior during simulated failures.

Planned Technologies
* Cloud Platform: Amazon Web Services (AWS)
* Programming Language: Python
* API Management: Amazon API Gateway
* Application Execution: AWS Lambda
* Database: Amazon DynamoDB
* Monitoring: Amazon CloudWatch
* Infrastructure as Code: Terraform
* Version Control: Git and GitHub

Security Considerations
* Use HTTPS for application communication.
* Apply least-privilege access permissions.
* Protect application credentials and secrets.
* Validate incoming user information.
* Restrict unauthorized access.

Testing Strategy
The application will be tested under normal operating conditions and simulated failure scenarios.

Project Status
